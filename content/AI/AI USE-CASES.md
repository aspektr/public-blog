
# Автомобильная промышленность и логистика
### Агенты для работы с клиентами

Одним из первых результатов партнёрства стало внедрение разговорных ИИ-технологий Google Cloud в систему Smart Cockpit HPC — встроенное в автомобиль решение с голосовым управлением.

Также пользователи могут воспользоваться мультимодальными возможностями Gemini: просто направив камеру смартфона на приборную панель, они получают полезную информацию об индикаторах и их значении.

- **Fiserv**, разработчик технологий для финансовых сервисов, с помощью **Gemini в Security Operations** может **резюмировать угрозы, находить решения и ускоренно реагировать на инциденты безопасности**.
    
- **Resistant AI** разрабатывает **ИИ-решения для борьбы с мошенничеством** в сфере финансовой документации и рабочих процессов с поддержкой Google Cloud. Эти решения **ускоряют проверку данных**, **снижают потери от мошенничества** и **ускоряют процессы андеррайтинга и обработки страховых выплат**.
