Для этого используется команда:

```bash
	scancel <JOBID>
```



---

### 📌 Примеры:

1. **Отменить конкретную задачу:**
    

```bash
	scancel 12345
```

2. **Отменить все свои задачи:**
    

```bash
	scancel -u $USER
```

3. **Отменить все задачи в определённой очереди:**
    

```bash
	scancel -p gpu
```

4. **Отменить все `PENDING` задачи:**
    

```bash
	scancel -t PD -u $USER
```

> `-t` фильтрует по статусу (`PD` — ожидает, `R` — выполняется и т.д.)

---

### ⚠️ Ограничения:

- Обычный пользователь может отменить **только свои** задачи.
    
- Администратор (`root` или `SlurmUser`) может отменить **любые** задачи.
    

---

### ✅ Что происходит при отмене:

1. SLURM завершает выполнение задачи (или удаляет из очереди).
    
2. Записываются логи об отмене.
    
3. Ресурсы (CPU, GPU, память) освобождаются.
